AP CSP Pseudocode
=================

.. raw:: html

	<p>The AP CS Principles Exam does not have a designated programming language associated with it. Instead a pseudocode is used. The <a href="../_static/assets/img/AP CSP Reference Sheet compressed.pdf" target="_blank">AP CSP reference sheet</a> is provided during the exam to help you understand the AP pseudocode format and the meaning of the questions on the exam.</p>
	 
	 
	 
	<p>The AP CSP pseudocode commands are also reviewed in the following lessons:
	<ul>
	  <li> Algorithm Basics: Robot commands </li>  
	  <li> Paint Pot: Variables and Assignment </li> 
	  <li> Paint Pot Projects: selection (if) statements </li> 
	  <li> Paint Pot Refactoring: Procedures </li> 
	  <li> Map Tour: Intro to Lists </li> 
	  <li> Logo I: AP CSP Robot Code and Loops </li>
	  <li> Logo II: Procedures with Parameters </li> 
	  <li>Caesar Cipher App: Functions with Parameters</li>
	  <li>Quiz App Projects: AP CSP List Commands and Loops with Lists</li>
	  <li>Pseudocode Tracing Exercises (the next lesson)   </li>  
	 </ul>
